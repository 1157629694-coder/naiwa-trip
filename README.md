# 奶蛙的旅拍 · 在世界尽头留一张照片

> 仓库里的 `index.html` 是**打包后的单文件版**：样式、脚本、全部图片都已内联，双击即玩、可离线；分文件的源码在本地 `frog/` 目录（本仓库只放这一个发布文件，方便 GitHub Pages 直接托管）。


一个「风景 + 奶蛙艺术照」的旅拍网页小游戏。双击 `index.html` 即可打开，不需要服务器、不联网（图片都在本地）。

## 玩法

- 12 个地点，一页一站：整屏是真实名胜的照片，左下是奶蛙当天的手记（第三人称，句句提到奶蛙），右侧是**两张拍立得**——奶蛙被画进名画的二创照。
- 点任意一张照片 → 放大成一张「手账纸卡」：胶带、大图、画名、画派、这张照片单独的批注、当天天气那行、一枚「奶蛙在场」的印章，可以「上一张 / 下一张 / 合上」。
- 底部是线路图：墨点停在当前站，站名随车走；「盖上印章，去下一站」或直接点站号跳站；也可以按 `←` `→` `空格`（`Esc` 关放大页）。
- 右上「翻手账」看 12 站收集进度（每站两张，共 24 张）。走到第 12 站盖章后出现收尾页。

## 改法

- **换文案 / 换照片**：只改 `js/data.js`。每站一条：

```js
{ key:"fuji", kicker:"第 01 站 · 日本", title:"富士山", en:"MOUNT FUJI", coords:"35.36° N · 138.73° E",
  grade:"cool", note:"……奶蛙……", meta:"晴 · 湖面有风 · 第 1 天 · 蛙重一颗桃",
  arts:[ {src:"assets/art/fuji.jpg",  t:"《浪里的旅人》", s:"北斋之后 · 奶蛙版", c:"这张的批注……"},
         {src:"assets/art2/fuji.jpg", t:"《巨浪》",       s:"神奈川冲浪里 · 奶蛙版", c:"……" } ] }
```

- **加减站点**：数组长度变了，线路图与手账会自动跟着变（站号、进度都按数组算）。
- **调色**：`grade` 取 `cool / warm / dusk / cold`，控制背景滤镜。
- **换素材**：艺术照来自 [Naiwa Hub 艺术合集](https://naiwahub.com/zh/memes?collection=art&sort=top)，实景来自 Wikimedia Commons / Wikipedia 页面首图；换成自己的图只要保持文件名对应。

## 怎么给别人打开（网址）

镜像已经起好了，三种地址：

| 场景 | 地址 |
| --- | --- |
| 本机 | `http://127.0.0.1:8787/frog/index.html` |
| 同一 WiFi 的手机 | `http://192.168.3.4:8787/frog/index.html` |
| 公网（任何人） | 见下方隧道说明 |

静态服务就是一条命令（在仓库根目录跑）：

```bash
python -m http.server 8787 --bind 0.0.0.0
```

公网地址是把上面的 8787 端口通过 SSH 隧道映射出去（serveo.net）：

```bash
ssh -T -R 80:localhost:8787 serveo.net
```

它会打印一行 `Forwarding HTTP traffic from https://<随机串>.serveousercontent.com`，那个域名就是公网网址。注意：

- 免费隧道每次重连域名会变；浏览器首次打开会看到一张 Serveo 的英文警告页，点 **Continue to Site** 就进游戏。
- 隧道依赖这台电脑和那条 ssh 进程一直活着，关机或断网就失效。
- 想要固定网址、不出现警告页，需要换成 Cloudflare Tunnel / Vercel / GitHub Pages 这类带账号的托管。

## 手机上看

窄屏（≤900px）是另一套版式，不是把桌面压扁：

- 顶栏、照片区、正文按顺序竖排，**顶栏不再浮在照片上**（照片不会盖住「奶蛙的旅拍 / 01-12 / 翻手账」）；
- 两张拍立得改为上左 / 下右错位叠放，后排那张贴到照片区顶部，不会被裁掉一角；
- 正文字号 12.5px / 行高 1.82，长手记也挤不到按钮；「点照片，可以翻到背后看」这类提示在手机上隐藏，空格让给正文；
- 底部按钮用 `env(safe-area-inset-bottom)` 避开 iPhone 的横条；「上一站」缩成小按钮，主按钮撑满；
- 放大页改成上大图下手账，图最高 36vh，标题 / 批注 / 天气 / 印章 / 上一张下一张一屏放得下，不用滚动；
- 竖排水印「李小涵 制作」在宽屏贴左边，手机挪到右下角。

## 局域 / 公网怎么打开

- 直接双击 `index.html`：能用，但 `file://` 下部分浏览器会拦本地图片缓存，推荐起个静态服务。
- 本机：`python -m http.server 8787`，打开 `http://127.0.0.1:8787/frog/index.html`
- 手机同 Wi-Fi：`http://<电脑局域网IP>:8787/frog/index.html`（Windows 防火墙需放行 python.exe）
- 公网临时链接：`ssh -T -R 80:localhost:8787 serveo.net`（地址每次会变；`tools\serve_naiwa.cmd` 是带自愈循环的版本）

## 背景音乐（BGM）

- 右下角胶囊按钮就是开关：亮着（玫瑰色 + 三条跳动的横线）代表在放，暗着代表停；按 **M** 也能切。
- 歌是李荣浩《耳朵》，**音频文件不放仓库**（版权），要自己提供：把 mp3 放到 `frog/assets/bgm.mp3`，或运行 `tools\设置BGM.ps1 -Path "你的文件.mp3"`。
- 放好后重新打包发布：`python $env:TEMP\buildweb2.py` 会把 mp3 以 base64 内联进 `gh_web/index.html`，再上传覆盖 GitHub 上那份 `index.html` 即可。
- 没有 mp3 时按钮显示「放歌」，点一下会提示「缺 bgm.mp3」，游戏本身不受影响。
- 浏览器不允许自动播放有声内容，所以音乐在点「开始旅行」那一下才起播（已按这个规则接好）。
